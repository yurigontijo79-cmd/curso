# Plano do Curso: Fundamentos de Programação

## Carga horária

- Total: 24 horas
- Formato sugerido: 8 encontros de 3 horas

## Público-alvo

- Pessoas iniciantes sem experiência prévia em programação.

## Módulo 1 — Introdução e lógica (3h)

### Conteúdos
- O que é programação
- Algoritmos e pensamento lógico
- Entrada, processamento e saída

### Prática
- Resolver 5 problemas de lógica em pseudocódigo.

## Módulo 2 — Variáveis e tipos de dados (3h)

### Conteúdos
- Variáveis e constantes
- Tipos primitivos (texto, número, booleano)
- Conversão de tipos

### Prática
- Criar um programa de cadastro simples no terminal.

## Módulo 3 — Condicionais (3h)

### Conteúdos
- `if`, `else if`, `else`
- Operadores relacionais e lógicos

### Prática
- Implementar verificador de aprovação (nota/frequência).

## Módulo 4 — Repetição (3h)

### Conteúdos
- `for` e `while`
- Controle de fluxo (`break`, `continue`)

### Prática
- Criar tabuada e cálculo de média com laços.

## Módulo 5 — Funções (3h)

### Conteúdos
- Declaração e chamada
- Parâmetros e retorno
- Organização de código

### Prática
- Criar biblioteca de funções matemáticas básicas.

## Módulo 6 — Estruturas de dados básicas (3h)

### Conteúdos
- Listas/arrays
- Objetos/dicionários
- Iteração em coleções

### Prática
- Sistema simples de lista de tarefas.

## Módulo 7 — Git e colaboração (3h)

### Conteúdos
- `init`, `add`, `commit`, `push`
- Branches e pull request
- Mensagens de commit

### Prática
- Simular fluxo de colaboração com branch e PR.

## Módulo 8 — Projeto final (3h)

### Desafio
Desenvolver um projeto de terminal com:
- Entrada de dados
- Validações
- Funções reutilizáveis
- Persistência simples (arquivo local)

### Entrega
- Código-fonte
- README com instruções
- Demonstração curta (vídeo ou apresentação)

## Avaliação sugerida

- Exercícios por módulo: 40%
- Participação e revisão de código: 20%
- Projeto final: 40%
